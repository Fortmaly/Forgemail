# Forgemail

**Simple temporary email library for Python** – create disposable inboxes, fetch messages, and integrate temp emails into your projects.

> **Educational use only.** This tool is meant for learning, testing, and development. Please respect the terms of service of the email providers.

---

## ✨ Features

- 📧 **Create a temp email** – get token + address in one function call  
- 📬 **Fetch all messages** – full JSON response (dictionary or list)  
- 🧼 **Optional HTML cleaning** – convert `&nbsp;`, `<br>`, etc. to readable text  
- ⚡ **Lightweight** – only needs the `requests` library  
- 🔌 **Easy to extend** – use the raw API responses for your own automation
